# Мобильные приложения Путевой (Android)

Два клиента под популярные Android (Samsung, Xiaomi/Redmi, Huawei/Honor, Realme, Pixel, TECNO):

| Кто | Адрес | Вход |
|-----|-------|------|
| Водитель | `/driver.html` | госномер + код машины |
| Менеджер / админ | `/manager.html` | логин и пароль учётной записи |

## Что умеет водитель
- Рейсы машины (после того как менеджер завёл их в программе)
- Одометр **отдельно** на погрузке и разгрузке
- Чеки на соляру
- Офлайн: данные на телефоне, синк при появлении сети

## Что умеет менеджер / админ
- Вносить и править **рейсы** с телефона
- Вносить **расходы**
- **Выгружать отчёты** Excel / PDF

## Android-оптимизация
- Safe-area под вырезы и жестовую навигацию (One UI, MIUI, Pixel)
- Высота `100dvh` вместо «прыгающего» `100vh` в Chrome
- Поля ввода от 16px — без авто-зума клавиатуры
- Кнопки от 48px, `touch-action: manipulation`
- PWA: «Установить приложение» / «На экран Домой» в Chrome и Samsung Internet

## Локально (без Amvera)

```bash
npm run dev
```

- Водитель: http://localhost:5173/driver.html — демо `А123ВС 116` / `1234`
- Менеджер: http://localhost:5173/manager.html — ваша учётная запись

На телефоне в той же Wi‑Fi: `http://<IP-компа>:5173/driver.html` или `/manager.html`.
